# 机器人软件测试报告

## 1. 测试概述

本项目用于模拟机器人软件测试岗位中的测试工作。

本轮测试主要针对机器人控制器、工业控制器以及 Teach Pendant 示教器的核心功能进行验证。

测试采用 Python + pytest 自动化测试方式，并结合正常、边界和异常场景进行测试。

充电功能本阶段暂不实现，也不纳入本轮测试范围。

---

## 2. 测试对象

本轮测试对象包括：

- Robot Controller 机器人控制器
- Industrial Controller 工业控制器
- Teach Pendant 示教器

## 5. 测试策略

本轮测试采用以下测试方法：

### 5.1 正常测试

验证系统在正常输入和正常操作流程下是否能够按照预期工作。

例如：

- 正常启动机器人
- 正常停止机器人
- 正常执行运动
- 正常切换 Teach Pendant 模式

### 5.2 边界测试

验证系统在临界值附近的行为。

例如：

- distance = 0
- distance = 1
- distance = 最大允许值
- 电量刚好满足运动要求
- 电量刚好为 0

### 5.3 异常测试

验证系统面对非法输入或异常状态时是否能够正确处理。

例如：

- 负数距离
- 超出当前电量的运动距离
- 未启动状态下执行运动
- 电量为 0 时启动
- 非法 Teach Pendant 模式

### 5.4 参数化测试

针对多个输入值执行相同测试逻辑，以提高测试覆盖范围。
