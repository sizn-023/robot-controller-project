# 机器人软件测试点设计

## 1. 机器人控制器

### 1.1 初始状态
- 控制器创建后是否处于正确的初始状态
- 初始机器人是否处于停止状态
- 初始电池电量是否正确

### 1.2 启动功能
- 正常启动机器人
- 已启动状态下重复启动
- 异常状态下启动机器人

### 1.3 停止功能
- 正常停止机器人
- 未启动状态下停止机器人
- 已停止状态下重复停止

### 1.4 机器人运动
- 正常运动距离
- 运动距离为 0
- 运动距离为负数
- 超出允许范围的运动距离
- 未启动机器人执行运动
- 电量不足时执行运动

### 1.5 电池功能
- 正常电量下运动
- 临界电量下运动
- 电量不足时禁止运动
- 运动后电量正确减少
- 电量不能低于 0


## 2. 工业控制器

### 2.1 初始状态
- 控制器初始状态是否正确
- 初始电池电量是否正确
- 初始机器人状态是否正确

### 2.2 启动与停止
- 正常启动
- 重复启动
- 正常停止
- 重复停止

### 2.3 运动控制
- 正常运动距离
- 运动距离为 0
- 负数运动距离
- 超出最大运动距离
- 未启动时执行运动
- 电量不足时执行运动

### 2.4 电池消耗
- 正常运动后的电量变化
- 多次运动后的电量变化
- 临界电量测试
- 电量不足后的行为
- 电量不应出现负数


## 3. Teach Pendant

### 3.1 初始状态
- 示教器初始模式是否正确

### 3.2 模式切换
- AUTO 模式切换
- MANUAL 模式切换
- AUTO → MANUAL
- MANUAL → AUTO
- 重复切换相同模式

### 3.3 异常输入
- 非法模式名称
- 空字符串
- None
- 其他无效输入

### 3.4 状态一致性
- 有效切换后状态是否正确
- 非法输入后原状态是否保持
- 重复切换后状态是否正确


## 4. 测试方法

### 4.1 正常测试
验证正常输入和正常操作下系统是否符合预期。

### 4.2 边界测试
重点测试：

- 0
- 1
- 最大允许值
- 最大值 + 1
- 最小允许值
- 最小值 - 1

### 4.3 异常测试
重点测试：

- 负数
- 空值
- None
- 非法字符串
- 错误状态下执行操作


## 5. 测试优先级

### P0 - 核心功能
- 机器人启动
- 机器人停止
- 机器人运动
- 工业控制器启动
- 工业控制器运动
- Teach Pendant 模式切换

### P1 - 重要功能
- 电池消耗
- 电量不足处理
- 运动前置条件
- 异常输入处理

### P2 - 一般功能
- 重复操作
- 极端边界
- 非核心异常场景
